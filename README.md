# SOC_Model


SOC Lab Complete Pack — Synthetic Training Data
=================================================
This archive includes:
1) security.log: a combined raw syslog-style feed for the second SOC Lab question paper.
2) reference/: GeoIP, threat-intelligence, and asset-criticality lookup tables.
3) question_datasets/: separate question-specific CSV/log files for the first SOC Lab question paper (Q1–Q30).

All data is synthetic and intended for isolated educational use. IPs/domains use documentation-style examples where possible.
The question-specific files are starter datasets, not real incident evidence. Students should write Python parsers/analysis and justify findings.
